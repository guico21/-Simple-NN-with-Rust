## What is this project about
This is a project in building a simple NN that is able to correctly predict which digits have been written on a piece of paper. 

The goal is to build the network from scratch using Rust, this should give me the ability to:
1. Better understand how NN works inside out (key foundation concepts).
2. Learn more about Rust.
3. Swear multiple times a day.
